# Settings UI

This folder contains the zero-build frontend for VoiceFlow Overview, History,
Settings, Help, and advanced diagnostics:

- `index.html` defines the application surfaces.
- `src/styles.css` defines the dark neutral, teal-accented visual system.
- `src/main.js` handles localization, rendering, drafts, save state, and the
  localhost Settings bridge.
- `src/overview-analytics.js` derives the seven-day Overview presentation from
  usage-ledger schema v2.
- `src/provider-settings-model.js` owns frontend provider preset metadata.

For live use, open the URL printed by:

```powershell
cargo run -p input-host -- --serve-settings
```

The loopback server serves UI and API from the same origin, injects a
per-process token for state-changing routes, and disables caching on the
token-bearing bootstrap. Direct `file://` loading is an offline, read-only
view.

## Overview And History

Overview shows a seven-day inserted-text and estimated-time-saved chart plus
total dictation duration, inserted text, estimated time saved, and average
dictation speed. It reads the usage ledger independently of History retention.
Recent local content can be privacy-masked. History uses the user-facing
categories Dictation, Text Edit, and Instructed Input and omits provider detail
when legacy records do not contain reliable metadata.

## Settings

The five sections, in order, are General, Voice & Output, History &
Privacy, AI Provider, and Advanced. The page preserves dirty drafts during
background runtime refresh, reports accurate save state, and communicates when
changes apply immediately, on the next session, or on the next AI request.

The Provider form stays full width across presets. Built-in providers supply a
default endpoint while keeping model/model ID editable. Custom endpoint drafts
survive background effective-status polling, and Advanced details show one
full-width effective value per row. API-key save/clear, Credential Manager
status, Reset to provider default, and sanitized Test Connection are available
in live mode.

Advanced includes the Prompt Editor for light/structured dictation, Text Edit
and Instructed Input. Changes are saved per prompt in app data and apply to
subsequent requests. Reset pins the built-in prompt without deleting file overrides.

Live `/src/runtime-state.js` is generated by the Settings server. The disk mirror
is `runtime/settings-state.js` beside the settings file. Static source previews
do not automatically receive live history; portable builds contain an empty placeholder.
