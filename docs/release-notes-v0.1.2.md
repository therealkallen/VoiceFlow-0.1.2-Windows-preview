## VoiceFlow 0.1.2 — Windows preview

Download **VoiceFlow-0.1.2-windows-x64-portable.zip**, extract it, and open
**VoiceFlow.exe**. Python and the local SenseVoice model are included.

- Local dictation, optional AI cleanup, rewriting and translation.
- Recording shortcuts, floating status indicator, desktop settings and tray.
- Chinese/English interface and local history.

Requires Windows x64 and WebView2 Evergreen Runtime. AI features require your
own provider/API key and send text to that provider. This build is unsigned;
target-app compatibility is still being tested.

The ZIP includes third-party licenses and corresponding source for MPL
components. VoiceFlow source is MIT; model weights have separate FunASR terms.
The accompanying SHA256 file can be used to verify the download.

Windows 预览版：下载 ZIP，完整解压后打开 VoiceFlow.exe。已包含 Python 和模型，无需另外下载。
需要 WebView2；AI 功能需要自己的 API key。本版本未签名。
